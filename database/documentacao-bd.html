01
Visão geral

Introdução

A Base de Dados BibliotecaSystem foi desenvolvida programador Juliano Soca Barros para suportar um Sistema de Gestão de Biblioteca, permitindo o armazenamento, organização, consulta e processamento das principais informações relacionadas ao funcionamento de uma biblioteca.

A base foi estruturada segundo os princípios do modelo relacional, garantindo integridade, consistência, segurança e facilidade de manutenção dos dados.

Objetivo da documentação

Apresentar de forma clara a estrutura física, lógica e funcional da base de dados.

02
Finalidade

Objetivos da Base de Dados

A base de dados tem como objetivo centralizar e controlar as informações necessárias para o funcionamento da biblioteca.

Gerenciar usuários, funcionários e administradores.
Cadastrar livros, autores e categorias.
Controlar exemplares físicos.
Registrar empréstimos e devoluções.
Controlar multas e pagamentos.
Gerar informações para o dashboard.
Automatizar processos através de Triggers e Events.
Garantir auditoria e mecanismos de backup.
